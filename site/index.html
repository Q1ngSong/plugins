下载安装

下载就能用。电脑上要有 git，Claude Code 和 Codex 至少装一个。

WINDOWS 10 / 11X64

Windows

PluginHub_<版本>_x64-setup.exe

双击安装，装在当前用户目录下，用不着管理员权限。目录链接用的是 junction，普通用户就能建。

NSIS 安装包免管理员计划任务
到 Releases 下载 ↗
MACOS 10.15+UNIVERSAL

macOS

PluginHub_<版本>_universal.dmg

打开后把「插件中心」拖进「应用程序」。Apple 芯片和 Intel 的 Mac 都能用，目录链接用的是符号链接。
